## 2. The recurring moves (the abstraction — what every entry shares)

Confirmed across the luxury/editorial/SaaS/studio sets. These are the durable part:

1. **Restraint as the signal** — premium is what's *removed*: near-zero copy, one accent, negative space placed like type.
2. **Type-as-architecture** — a distinctive display + calm body at dramatic scale carries the whole hierarchy; many premium sites are type + grid alone.
3. **One signature moment, not effects everywhere** — the wow budget is spent once, tied to the brand.
4. **Show the real thing** — real product/photography/interface; stock and obvious-AI imagery are now *negative* trust signals.
5. **Editorial discipline** — the page is a magazine: a grid broken deliberately, contained↔full-bleed rhythm.
6. **Monochrome (or warm-neutral) base + one disciplined accent.**
7. **Hero states a feeling, then proves it** — emotional register before specs.
8. **Coherence end-to-end** — cursor, type scale, motion grammar, spacing applied as one designed object.

(Concrete values for these live in `frontend-public-site-conventions` craft layer; the process that applies them is `premium-web-method`.)

## 3. Exemplar shortlist — the ONE move each (snapshot, re-pull live)

Long-stable anchors (rarely change) and fresh pulls from the galleries above (dated 2026-06 — verify before citing). Each is reduced to its *load-bearing* move so it's studyable, not just admired.

**Luxury / fashion / jewellery**
- **Aesop** — the storefront as a *magazine*: monochrome cream, editorial product essays above modest still-life, one sparing accent. Proof that restraint + reading-first type *is* the luxury.
- **Bottega Veneta** — full-bleed product photography *is* the layout; near-zero copy. Confidence expressed by refusing to explain.
- **Cartier** (incl. Watches & Wonders 2026, Awwwards) — restraint + a single brand-red accent; the product pops because nothing else competes; an immersive set-piece reserved for one moment.
- **Delvaux digital flagship** (Awwwards luxury) — gallery-grade e-comm: product treated as a hero object, merchandising clutter removed.

**Editorial / gallery / studio**
- **Obys Agency** / **Index Studio** work (SiteInspire) — type-as-architecture + a custom motion grammar applied with total consistency.
- **Mennour**, **Field Studies** (SiteInspire) — calm modular grid where typographic contrast alone carries hierarchy; deliberate grid breaks.

**SaaS done right (the rare premium product site)**
- **Stripe** — every product page is a self-contained essay; custom-consistent illustration; live code that shows what integration *feels* like.
- **Linear** — one line about how the product *feels*, then a real product clip (never stock illustration); near-monochrome, modular not grid-locked.
- **Vercel** — mostly dark, mostly type, densely informative; the "blueprint" aesthetic mirrors the developer's mental model.

**Hospitality / restaurant**
- **Ballena**, **Relais Rossar** (Awwwards luxury) — cinematic full-bleed imagery + warm-minimal type; storytelling (place/flavor/people) instead of a menu dump.

**WebGL apex (borrow the commitment, not the tech)**
- **Igloo Inc** (Awwwards Site of the Year 2025) — the *entire* UI rendered in one WebGL world; "one engine, one idea" taken to the limit. The lesson is total concept commitment, not the shaders.
- **Active Theory** — the homepage is an engine you operate; you *live* the capability instead of reading about it.

**The Persimmon takeaway:** moves 1, 2, 5, 6, 7 (restraint, type-as-architecture, editorial grid, monochrome+one accent, feeling-first hero) are achievable in vanilla CSS/Tailwind and carry ~80% of the premium signal at near-zero cost. Reserve "one signature moment" for a single tasteful scroll-reveal or a bespoke structural artifact (the client's own work as the interface) — not a WebGL planet.
